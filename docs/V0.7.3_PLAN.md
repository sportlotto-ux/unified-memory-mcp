## В v0.7.3 (быстрые, бесспорно)

- [x] **A1 — weight `um_links` в графовом скоринге.** В `Router._bfs_links` оценка
  узла умножается на вес линка (`link_neighbors` уже отдаёт `weight`, дефолт 1.0 →
  обратно совместимо). `score = base * weight`. Тест: линк с weight=2 поднимает
  узел выше равного при 1.0.
- [x] **A4 — FTS-сниппет (только FTS-плечо).** `store.fts_search` кладёт
  `snippet(um_fts, 2, '[', ']', '…', 8)` в `Hit.extra["snippet"]`; `Hit.body`
  остаётся полным (точные `h.body`-ассерты тестов не ломаются). `server.mem_recall`
  показывает сниппет, если он есть, иначе прежний head-truncate 2000. `rrf_fuse`
  уже сохраняет `extra`.
- [x] **B7 — `mem_doctor(mode="archive_check")`.** Read-only: `{file_exists, stubs,
  archived_rows, orphans, archive_path}`. `orphans` — заглушки в горячей, чей
  `externalized_ref` id не найден в архиве (парсинг `label#id`). Архив не создаётся.
- [x] **B8 — `mem_doctor(mode="secret_scan")`.** Read-only скан горячего стора
  каталогом redaction (`um_messages.content`, `um_facts.body`, `um_summaries.body`,
  `um_edges` predicate / `um_entities` names). Отчёт **без значений**:
  `{pattern, kind, id}`, плюс `total`, кап 50. Защита forward-only-обещания.
- [x] **B9 — WAL checkpoint(TRUNCATE) в maintenance + строка в статус.**
  В `_maybe_maintenance` (never-raises) добавить `PRAGMA wal_checkpoint(TRUNCATE)`;
  в `mem_status` — `wal_bytes` (размер `<db>-wal`, 0 если нет). Сначала факт роста
  виден в статусе, потом чистим.
- [x] **B10 — кап входного текста `UM_MAX_TEXT_CHARS` (дефолт 200000).** Один гейт в
  `Ingest._clean` (накрывает remember/fact/batch/будущее) — громкий `ValueError`,
  не тихая обрезка. Config-поле + валидация >0.
- [x] **A5 — детект дублей в `hygiene()` (read-only).** Гейт: есть вектора; строго
  внутри owner; фиксированный порог косинуса (0.95, задокументирован); cap пар 20.
  `out["duplicate_facts"] = [[table, id_a, id_b, round(score,3)], ...]`.
- [x] **№22 — graceful-skip висячих линков + счётчик.** BFS уже не падает (`node_ok`);
  добавить `self._bfs_skipped` (конец не существует/тело недоступно) и в diagnostics
  `bfs.skipped_missing`. Тест: удалил факт-конец → обход жив, счётчик > 0. Каскадное
  удаление линков — отдельное решение (GDPR vs provenance), НЕ в 0.7.3.
- [x] **C11 — аннотации MCP-тулов.** Имена хинтов сверить с установленным `mcp==2.2.0`
  (Context7, не по памяти). Таблица: `compact` — не read-only (пишет саммари);

## v0.8 (спроектированное, не «за час»)
- [x] **E20 golden-eval** — ДО любых скоринговых правок. `tests/test_eval.py`
  (изолированный tmp-стор, замороженные часы → детерминизм, прод-дефолт конфиг,
  ассерты на вхождение в топ-N). Метрики: **hit@3** (бинарь) + **MRR**.
  **Baseline на v0.7.3 (n=24): hit@3 = 1.000, MRR = 0.896.** Пороги с запасом:
  **hit@3 ≥ 0.95, MRR ≥ 0.85**. Покрытие плеч: FTS-дословно (9), вектор-парафраз
  (8, синтетический `LexicalBackend` — детерминированный bag-of-tokens+SYN),
  граф-хоп (3, пары без общих токенов — иначе MMR демотивирует цель), истёкшее-
  скрыто (2). Ранжирующий PR держит eval зелёным либо правит фикстуры громко.
- A2 вектора на update/reopen (эмбеддинг в Ingest-пути, `_commit` для batch).
- B6 import + C13 batch-remember + D16 JSONL-export — единым куском, общий формат
  дампа (fresh-id remap, namespace owner, skip-never-overwrite).

  (`assemble` — хвост, `maybe_compact` — голова), D14-частично (`recent`/сессии
