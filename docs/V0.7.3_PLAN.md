  узла умножается на вес линка (`link_neighbors` уже отдаёт `weight`, дефолт 1.0 →
  обратно совместимо). `score = base * weight`. Тест: линк с weight=2 поднимает

- [x] **B7 — `mem_doctor(mode="archive_check")`.** Read-only: `{file_exists, stubs,
  archived_rows, orphans, archive_path}`. `orphans` — заглушки в горячей, чей
  `externalized_ref` id не найден в архиве (парсинг `label#id`). Архив не создаётся.

  В `_maybe_maintenance` (never-raises) добавить `PRAGMA wal_checkpoint(TRUNCATE)`;

## v0.8 (спроектированное, не «за час»)
> **РЕЛИЗ 0.8.0** — весь раздел ниже выполнен (E20→A2→D16+C13+B6→E21/E18/D15/D14/C12),
> breaking нет, E20 не сдвинулся (hit@3=1.000, MRR=0.896). Дальше — D17-бенч как ключ
> к A3-эксперименту либо внешние поводы; стратегические F-пункты — не блокеры.
- [x] **E20 golden-eval** — ДО любых скоринговых правок. `tests/test_eval.py`
  (изолированный tmp-стор, замороженные часы → детерминизм, прод-дефолт конфиг,
  ассерты на вхождение в топ-N). Метрики: **hit@3** (бинарь) + **MRR**.
  **Baseline на v0.7.3 (n=24): hit@3 = 1.000, MRR = 0.896.** Пороги с запасом:
  **hit@3 ≥ 0.95, MRR ≥ 0.85**. Покрытие плеч: FTS-дословно (9), вектор-парафраз
  (8, синтетический `LexicalBackend` — детерминированный bag-of-tokens+SYN),
  граф-хоп (3, пары без общих токенов — иначе MMR демотивирует цель), истёкшее-
  скрыто (2). Ранжирующий PR держит eval зелёным либо правит фикстуры громко.
- [x] **A2 — вектора на update/reopen** (эмбеддинг в Ingest-пути, `_commit` для batch).
  `Ingest.update_fact` = обёртка над `Store.update_fact`; после `superseded`/`reopened`
  зовёт `_embed_fact` (по `Store.fact_row`). `Ingest.upsert_fact` тоже переведён на
  `_embed_fact`. Batch-путь (`_batch_op`) и тул `mem_update` идут через Ingest.
  Тесты `tests/test_a2_embed.py` (5): новая версия эмбеддится, reopen переэмбеддит,
  backend=None → no-op, rollback батча уносит вектор, серверный `mem_update`.
  E20 до/после: hit@3=1.000, MRR=0.896 — без изменений.
- [x] **D16 → C13 → B6 — формат дампа, batch-remember, импорт.**
  - **D16**: экспорт — стриминговый **JSONL** (`um-export-jsonl`; строка 1 — header:
    format/schema_version/exported_at/source_db/counts; далее `{table,row}`). um_fts/
    um_vecidx исключены (производные), um_meta дампится (импорт читает только schema_version).
    Вектора base64. Ридер понимает и legacy single-JSON (детект по первой строке).
  - **C13**: четвёртый batch-op `remember` (message) через `Ingest.remember_message`
    (`_commit`-проброс, deferred-compact). Тест атомарного откката сессии.
  - **B6**: `python -m unified_memory.import_dump <file> [--owner] [--dry-run]` (БД из
    UM_DATABASE_PATH). Fresh-id remap всегда; порядок entities→facts→messages→summaries→
    edges→links→vectors (+`Store.rebuild_fts()`); аддитивность (ноль UPDATE существующих),
    слот-конфликт → skip+счётчик; owner-override; **без `_clean`**; неизвестная таблица/
    новейшая schema_version → отказ; весь импорт в `transaction()` (dry_run тем же контуром).
    Работает без backend (вектора из дампа). Тесты `tests/test_import.py` (9).
  - **E20 после связки: hit@3=1.000, MRR=0.896 — без изменений** (импорт аддитивен,
    ранжирование существующего стора не трогает).
