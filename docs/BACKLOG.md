## P4-defer — точная токен-бюджетная арифметика (`mem_assemble`) на смешанном тексте
RU-aware эвристика (`ASCII/4 + не-ASCII/2`) детерминирована, но на смешанном
RU/EN/коде погрешность накапливается иначе, чем на однородном тексте. Пороги
компакшна это переживают; для жёсткого бюджетного счёта (`mem_assemble`) нужен
точный tiktoken → `pip install -e .[tokens]` (в README помечен как рекомендуемый).
Идея на будущее: сделать `.[tokens]` рекомендуемым дефолтом в доках/инсталле и,
возможно, помечать в `mem_status`, что оценщик эвристический (и бюджеты — оценка).

## P3.3 — `bump_tokens` не уменьшается при архивации → P4-defer (нейтрализовано A4)
Давление компакшна считается по счётчику токенов сессии; после выноса сообщений
в архив счётчик завышен → лишние саммари. Практический вред снят фиксом A4
(аудит-5): заглушки `[archived]` отфильтрованы из `session_messages`/`assemble`/
`compact`/`recent`, поэтому завышенный счётчик уже не тянет архивный текст в
саммари. Остаточный тихий перерасход — P4. Перенесено, не чинится в v0.7.1.

## ✅ P4.8 — вектора вытесненных/истёкших фактов (выполнено: `9e518cb`)
В supersede-ветке `_upsert_fact` и expire-ветке `update_fact` вектор старой версии
удаляется (`um_vectors` + `_vec_delete`). FTS-строку старой версии НЕ трогаем — на
ней держится `include_expired`. Следствие: reopen после expire возвращает факт без
вектора до `mem_reindex` (тот же гэп, что у update-версий, — в README).

## ✅ P3.5 — age-based retention (а) — `mem_doctor(mode=retention)` (выполнено: `f0ddedd`)
Добавлен режим `mem_doctor(mode=retention, apply)`: `before_ts = now - retention_days*86400`,
dry-run → `would_move`, apply → вынос батчами до опустошения среза (идемпотентен),
`retention_days=0` → no-op, пустой прогон архив не создаёт (P3.1-стиль). Ленивый
недельный проход на ingest остаётся.

## PyPI-публикация — отложено (явный триггер)
В PyPI не публикуем до **первого внешнего потребителя ИЛИ решения о v1.0** (что раньше).
Причины: нужен токен/trusted-publishing + release-workflow, дисциплина версий и бремя
поддержки (yank, issues из чужих окружений). До триггера 100% сценариев покрывает
`git clone` + `pip install -e .` (см. README). Триггер не терять.
