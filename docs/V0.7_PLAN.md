# v0.7 PLAN — типизированные связи + batch + diagnostics + export

Решения — в **`docs/ADR-001-typed-links.md`** (читать первым). Цель: +~20 тестов
(→ ~195). TDD (красный → фикс), live MCP-check на каждом пункте. Версия 0.7.0.

## Порядок

0. **ADR-001** — модель концов, словарь из 4, BFS-семантика. ✅ ГОТОВО
1. **Схема `um_links`** — новая таблица (не ALTER), индексы, partial unique (D3).
2. **`mem_link`** — write: валидация концов (D4), дедуп (D3), закрытый `rel` (D2):
   `mem_link(src, dst, rel, weight=1.0, session_id="", owner="")`, `src`/`dst` в
   формате `"fact:3"` / `"message:12"` (как refs в `mem_evidence`).
3. **Жизненный цикл** (D6): `mem_forget(kind=link)` — жёсткое;
   `mem_update(kind=link, valid_until=...)` — истечение/reopen.
4. **BFS-read** (D5): `mem_recall(hops=1, rel="")` по `um_edges ∪ um_links`; узел
   `(table, id)`; `as_of`/`include_expired`/`owner` — обе руки; `hops=1` = регресс-ноль.
5. **`mem_batch(ops, dry_run=False)`** (D7) — узкие ops, atomic, savepoint-предпросмотр.
6. **`mem_recall(diagnostics=true)`** — per-arm counts/вклад/timings, off по дефолту.
7. **`mem_doctor(mode=export)`** (D8) — JSON-дамп + `schema_version`, read-only.

## Готовность (критерии)

- Связь message→fact и fact↔fact видна в recall через `hops`; `contradicts` между
  двумя живыми фактами сохраняется и читается обратно.
- `hops=1` не меняет выдачу v0.6 (регресс-тест).
- Истёкшая/чужая связь не течёт в выдачу и в BFS; `as_of` режет **сквозь** линк.
- `mem_batch` с плохим op не пишет НИЧЕГО (rollback); `dry_run` не пишет; caps работают.
- `export` — валидный JSON с `schema_version`, стор не мутируется.

## Env

- `UM_BATCH_MAX_OPS` (дефолт `100`) — потолок ops в `mem_batch`.
- `UM_RECALL_MAX_HOPS` (дефолт `3`) — потолок `hops`.
- `UM_LINK_RELS` **не вводим**: закрытый `CHECK`, расширение — миграцией.

## Тесты (~20-24)

- **schema**: таблица+индексы+partial unique+CHECK (2)
- **write**: базовый линк, дедуп no-op, невалидный `rel`, висячий `src`, owner-mismatch,
  мусорный формат (5)
- **lifecycle**: expire скрывает, reopen, forget hard, owner/чужой (3)
- **BFS**: `hops=1` регресс, `hops=2` сквозь линк, `as_of` сквозь линк, `include_expired`,
  owner-isolation, `rel`-фильтр, identity `(table,id)` без склейки (6)
- **diagnostics**: off по дефолту, on → counts (2)
- **batch**: atomic ok, rollback, dry_run, cap/closed-ops (4)
- **export**: валидный JSON+`schema_version`, read-only (2)

## Сознательно не везём (подтверждено)

`import` (нет источника-донора), `mentions`/полный LCM-набор `rel`, `persona_*`,
`scratchpad_*`, `task_progress` (не память, а трекер), `sleep` (демона нет by design),
`sync_*`, `apply_pending`, `model_*`, отдельный `mem_inspect` (покрыт `mem_status`/
`mem_expand`/`mem_recall`).
