# v0.4 PLAN — следующая итерация (после сжатия контекста)

Контекст: v0.3.5 закрыл все 4 внешних аудита (54 теста). Ниже — бэклог
в порядке приоритета для публичного продукта. Каждый пункт: что, зачем,
критерий готовности.

## P0 — безопасность публичного использования

### 1. Redaction-гейт (секреты в памяти)
Что: `UM_REDACT_PATTERNS_ENABLED` (default **ON** — продукт публичный, LCM держал
off для себя), каталог `api_key,bearer_token,password,private_key` как у LCM.
Резать ДО SQLite/FTS/vectors/summaries, с необратимыми плейсхолдерами.
Готовность: тест кладёт `sk-...`/`Bearer ...` → в БД только плейсхолдер;
`mem_status` показывает флаг; доки предупреждают что redaction forward-only.

### 2. User-isolation (минимум)
Что: `session_id` → уже есть; добавить `owner` (tenant) на уровне БД + фильтр
во все запросы. Без этого общий хост читает чужое (задекларировано в README).
Готовность: два owner не видят данные друг друга во всех 10 тулах; миграция
старых БД (owner='' = default).

## P1 — качество recall (закрыть разрыв TOOL_MAP↔код)

### 3. Recency prior + MMR + scope_bias
Что: TOOL_MAP обещает, код даёт только RRF. Добавить в `Router`:
recency-приор по `created_at`, MMR-диверсификацию против дублей parent/children,
`scope_bias` для текущей сессии.
Готовность: тесты — свежий хит выше старого при равной релевантности;
дубли DAG не занимают весь топ-N.

## P2 — видимые фичи

### 4. `mem_recent` (temporal)
Что: выборки «что было сегодня/на неделе» поверх summaries+messages.
Дешевле `mem_evidence`, ценность для пользователей выше.
Готовность: тул + тесты на границах суток/недель (UTC, как LCM).

### 5. `mem_evidence` (сжатие evidence-семьи LCM)
Что: 1 тул вместо query_state/compute/compile/evidence_pack/retrieve:
режим `cite` (проверка утверждений по exact refs) + `compute` (даты/счёт/суммы).
Готовность: только если останется ресурс; иначе перенести в v0.5.

## P3 — масштаб и гигиена

### 6. sqlite-vec путь
Что: использовать `sqlite-vec` при наличии, brute-force как fallback.
Готовность: флаг в `mem_status`, паритет recall пробами, порог переключения
документирован.

### 7. Hygiene/repair в `mem_doctor`
Что: `doctor clean` (кандидаты мусора) + `repair` (FTS rebuild) backup-first,
как `/lcm doctor`. Сейчас doctor только читает.
Готовность: dry-run по умолчанию, apply только с флагом.
